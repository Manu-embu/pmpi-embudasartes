# Inventário dos Dados do Observatório da Primeira Infância de Embu das Artes

## 1. Finalidade

Este documento organiza as informações que poderão compor o Observatório da Primeira Infância de Embu das Artes e o monitoramento do PMPI 2026–2035.

O inventário tem cinco funções:

1. identificar os dados necessários;
2. indicar fontes e responsáveis;
3. organizar a atualização intersecretarial;
4. orientar a construção dos painéis e páginas do Observatório;
5. apoiar a definição e o monitoramento das metas do PMPI.

---

## 2. Estrutura padrão de cada indicador

Cada indicador deverá possuir, sempre que possível:

| Campo | Descrição |
|---|---|
| Código | Identificador único |
| Eixo | Área temática do PMPI |
| Tema | Assunto específico |
| Nome do indicador | Denominação oficial |
| Definição | O que o indicador mede |
| Fórmula | Numerador, denominador e multiplicador |
| Unidade | Número, percentual, taxa, razão ou índice |
| Linha de base | Valor inicial |
| Ano-base | Ano da linha de base |
| Série histórica | Período disponível |
| Fonte primária | Sistema ou base oficial |
| Fonte apresentada | Documento ou relatório utilizado |
| Secretaria responsável | Órgão que valida o dado |
| Corresponsáveis | Órgãos que contribuem |
| Abrangência | Municipal, territorial, unidade ou serviço |
| Desagregações | Idade, sexo, raça/cor, deficiência, renda, território |
| Periodicidade | Mensal, trimestral, semestral ou anual |
| Meta relacionada | Meta do PMPI vinculada |
| Visualização | Cartão, gráfico, tabela, mapa ou linha do tempo |
| Página do Observatório | Local de publicação |
| Situação | Disponível, parcial, divergente, a validar ou inexistente |
| Observações | Limitações e providências |

## 14. Regra de governança

Nenhum indicador deve ser publicado como linha de base oficial antes de:

- validação da secretaria responsável;
- confirmação da fonte;
- confirmação do ano;
- confirmação da fórmula;
- verificação do denominador;
- registro das limitações;
- aprovação da Comissão Intersetorial, quando aplicável.
