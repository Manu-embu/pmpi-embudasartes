## Implantação
1. Enviar os arquivos e pastas preservando a estrutura.
2. Copiar o conteúdo de `css/ADICIONAR_AO_FINAL_DE_STYLES.css` para o final do `css/styles.css` atual.
3. Atualizar o menu das páginas existentes para incluir Rede, Mapa e Planejamento.
4. O mapa exibirá marcadores após o preenchimento de latitude e longitude no JSON.

## Validação
Os dados do levantamento são administrativos e preliminares. Devem ser validados antes da apresentação como dados oficiais.
